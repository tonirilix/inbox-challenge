## Project docs

Read the relevant doc before changing the area it covers.

| Doc | Read it when |
| --- | --- |
| `ARCHITECTURE.md` | Changing structure, the state machine, endpoints, routing or adding an item type |
| `GLOSSARY.md` | Naming anything; use these terms exactly |
| `docs/adr/` | Questioning a decision about ports, item types or failed actions |
| `README.md` | Running the project; assumptions, tradeoffs and what comes next |

Principles and code patterns will be added to this table as they are written.

## Agent skills

### Issue tracker

Issues are local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
